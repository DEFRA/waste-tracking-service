# October Deadline - What you need to do soon
    
## What the Reporting Deadlines Mean for Software Providers

From 1 October 2026, all permitted or licenced waste reception sites in England and Wales will need to report their waste digitally using the [Report Receipt of Waste Service](https://www.gov.uk/guidance/report-receipt-of-waste). In Northern Ireland and Scotland this comes into effect on 1 January 2027. 

As a software provider you should ensure your software is ready for the required reporting dates to help your customers meet the reporting requirements.

## Key Steps to Integrate With the API:

1. [Register as a software provider](README.md) for the Receipt of Waste API Service.
2. Complete your integration with the API, you can refer to the [API Getting Started Guide](api-receipt-of-waste-getting-started-guide.md).
3. Complete your [PAT scenarios](api-production-approval-tests.md) and send the results to the DWT team to get access to production.
